FileRescue

A simple Python project to help make messy folders easier to understand.
Have you ever opened a folder and found so many files that it became difficult to find what you needed? 
That's the problem I wanted to work on with FileRescue.
I built FileRescue while learning Python and exploring how programs can work with files and folders. 
Right now, it scans a folder, identifies common file types using their extensions, and displays the results. 
It's an early version, and I plan to improve it as I learn more.
